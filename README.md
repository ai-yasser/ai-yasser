### Featured infrastructure & case studies

<details open>
<summary><strong>01 / FigCraft MCP bridge — AI-to-design infrastructure</strong></summary>

Built a **local MCP bridge** between **OpenCode (DeepSeek Flash 4.1)** and the **FigCraft CLI**, using stdio/control ports to route tool calls into real-time graphic and UI layout design. The point: connect an agent's planning loop to a practical design surface, rather than stopping at generated descriptions.

`OpenCode + DeepSeek → MCP bridge → FigCraft CLI → graphic / UI layout operations`

</details>

<details>
<summary><strong>02 / Sanity CMS — publishing without manual handoffs</strong></summary>

Integrated a custom **Sanity CMS** workflow for [Avoid Leakage](https://avoidleakage.com) so articles can be managed and published directly to the live website. Structured content and publishing are part of the system, not a separate copy-and-paste task.

`Content authoring → Sanity CMS → automated site publishing`

</details>

<details>
<summary><strong>03 / Outreach + paid acquisition — engineered for response</strong></summary>

Scaled **B2B cold-email outreach** for Japan-based used-car export firms, generating direct replies and high-ticket opportunities. Built **Meta Ads Manager** campaigns around Pixel tracking, custom events, and dynamic creative to drive verified sales and lead flow. Different channels; one principle: instrument the journey from message to outcome.

</details>

<details>
<summary><strong>04 / Anti-AI-slop content — automation with editorial judgment</strong></summary>

Orchestrated custom AI pipelines that create and auto-publish **visual carousels and posts** while avoiding generic, pattern-heavy AI copy. The goal is not just output volume: it is useful, audience-aware content with a recognizable point of view.

</details>
